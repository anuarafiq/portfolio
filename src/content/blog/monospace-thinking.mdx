I started writing everything in monospace font. IBM Plex Mono, specifically. I don't know how it changed how I think, but it did.

Perhaps - the fixed character width creates a consistency feeling and satisfaction. Each character have equal space, so complex words is easily recognizable compared to a precise word that takes eight.

Something associated with code. When I write in mono, I'm in a slightly more precise, technical headspace. Flow state, more structured.
