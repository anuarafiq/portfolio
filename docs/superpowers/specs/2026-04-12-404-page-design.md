# 404 Page Design

**Date:** 2026-04-12
**Status:** Approved

## Overview

Add a catch-all `*` route to `App.jsx` that renders a `NotFound` page. The page matches the existing editorial aesthetic — dry, no humor, no illustrated astronauts.

## Design

### Layout

Uses the **section-label pattern** established across all pages:

```
[mono stamp]   404. Not Found
[serif h1]     Page not found.
[divider]      border-t border-line
[body]         The page you're looking for doesn't exist or has moved.
[link]         ← Return home
```

### Typography & Tokens

| Element | Classes |
|---|---|
| Mono label | `font-mono text-[11px] text-rust uppercase tracking-widest` |
| Heading | `text-display-sm font-light font-serif` — `clamp(2.5rem, 6vw, 5rem)` |
| Divider | `border-t border-line my-6` |
| Body copy | `font-serif text-warm text-base leading-relaxed` |
| Link | `font-mono text-[11px] text-rust uppercase tracking-wider hover:text-ink transition-colors` |

### Behavior

- `document.title = "404 — Not Found"` set via `useEffect`
- Staggered framer-motion reveal (reuses `container` + `item` variants from `Home.jsx`)
- Layout: `max-w-5xl mx-auto px-6 pt-16`

## Files Changed

- `src/pages/NotFound.jsx` — new file
- `src/App.jsx` — add `import NotFound` and `<Route path="*" element={<NotFound />} />`
