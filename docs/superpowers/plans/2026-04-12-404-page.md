# 404 Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a catch-all 404 page that matches the portfolio's editorial aesthetic.

**Architecture:** Create a `NotFound` page component using the section-label pattern (`404. Not Found` mono stamp → serif heading → divider → body copy → link). Wire it up as a `path="*"` catch-all route in `App.jsx`. No new dependencies — reuses framer-motion and existing design tokens.

**Tech Stack:** React, React Router v6, Framer Motion, Tailwind CSS v4

---

### Task 1: Create NotFound page component

**Files:**
- Create: `src/pages/NotFound.jsx`

- [ ] **Step 1: Create the file**

```jsx
import { useEffect } from "react"
import { Link } from "react-router-dom"
import { motion } from "framer-motion"

const container = {
  hidden: {},
  show: {
    transition: {
      staggerChildren: 0.09,
      delayChildren: 0.05,
    },
  },
}

const item = {
  hidden: { opacity: 0, y: 18 },
  show: {
    opacity: 1,
    y: 0,
    transition: { duration: 0.55, ease: [0.22, 1, 0.36, 1] },
  },
}

export default function NotFound() {
  useEffect(() => {
    document.title = "404 — Not Found"
  }, [])

  return (
    <motion.main
      variants={container}
      initial="hidden"
      animate="show"
      className="max-w-5xl mx-auto px-6 pt-16"
    >
      <motion.p
        variants={item}
        className="font-mono text-[11px] text-rust uppercase tracking-widest mb-6"
      >
        404. Not Found
      </motion.p>

      <motion.h1
        variants={item}
        className="text-display-sm font-light font-serif text-ink mb-6"
      >
        Page not found.
      </motion.h1>

      <motion.div variants={item} className="border-t border-line mb-6" />

      <motion.p
        variants={item}
        className="font-serif text-warm text-base leading-relaxed mb-6"
      >
        The page you're looking for doesn't exist or has moved.
      </motion.p>

      <motion.div variants={item}>
        <Link
          to="/"
          className="font-mono text-[11px] text-rust uppercase tracking-wider hover:text-ink transition-colors duration-200"
        >
          ← Return home
        </Link>
      </motion.div>
    </motion.main>
  )
}
```

### Task 2: Wire up catch-all route in App.jsx

**Files:**
- Modify: `src/App.jsx`

- [ ] **Step 1: Add the import**

In `src/App.jsx`, add after the `ProjectDetail` import line:

```jsx
import NotFound from "./pages/NotFound"
```

- [ ] **Step 2: Add the catch-all route**

Inside `<Routes>`, add after the last `<Route>`:

```jsx
<Route path="*" element={<NotFound />} />
```

The full `<Routes>` block should look like:

```jsx
<Routes>
  <Route path="/" element={<Home />} />
  <Route path="/projects" element={<Projects />} />
  <Route path="/about" element={<About />} />
  <Route path="/notes" element={<Blog />} />
  <Route path="/notes/:slug" element={<BlogPost />} />
  <Route path="/projects/:slug" element={<ProjectDetail />} />
  <Route path="*" element={<NotFound />} />
</Routes>
```
